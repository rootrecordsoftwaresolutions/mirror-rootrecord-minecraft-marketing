# Minecraft Marketing

Free, open checklist and **copy-paste templates** for Minecraft Java server owners who want more players — without paying for ads on day one.

Use this repo to:

1. **List** your server on 15–25+ discovery sites and keep listings updated  
2. **Post** consistently on Reddit, Discord, and short-form social  
3. **Run** vote rewards, events, and referrals that actually retain players  

---

## Quick start

1. Copy [`templates/server-profile.example.md`](templates/server-profile.example.md) to `my-server-profile.md` (gitignore it locally — keep your IP private until ready).  
2. Fill in every `{{PLACEHOLDER}}` once.  
3. Open docs in [`copy/`](copy/) for the platform you are posting to.  
4. Track progress in [`MARKETING-DEPLOYMENT.md`](MARKETING-DEPLOYMENT.md).

**Placeholder convention:** `{{SERVER_NAME}}`, `{{SERVER_IP}}`, `{{WEBSITE}}`, etc. Replace all placeholders before publishing.

## What works best (summary)

Consistent activity beats one-time ad spam:

| Priority | Action |
|----------|--------|
| 1 | **15–25+** server lists, updated monthly |
| 2 | **Short-form video** 4–5×/week (Shorts, TikTok, Reels) |
| 3 | **Daily vote rewards** (Votifier + visible in-game perks) |
| 4 | **Weekly events** (builds, PvP, seasonal) |
| 5 | **Active Discord** — fast replies to new players |
| 6 | **Retention** — ask how players found you |
| 7 | **Track sources** — double down on what works |

## Vote setup (generic)

Most listing sites support **Votifier** or **NuVotifier**. Install on your server, open the vote port on your host, then paste host/port into each listing panel. Common listeners: built-in vote plugin rewards, NuVoter, or custom commands.
